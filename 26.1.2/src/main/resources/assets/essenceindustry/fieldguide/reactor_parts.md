# Craft reactor and fuel-plant parts

These parts use ordinary crafting materials. Nothing here requires AE2. See each build page for **placed** quantities; recipes may make several blocks at once.

[Starter reactor](reactor_building.md) - [Enricher](fuel_enricher.md) - [Reprocessor](fuel_reprocessor.md) - [Fabricator](fuel_fabricator.md)

## Reactor Casing

One casing for reactor walls, edges, fuel plants and turbines. Connected details follow the formed structure. Older Frames and Pressure Panels still work; break them or craft them alone to recover the shared casing.

<Recipe id="essenceindustry:reactor_casing" />



## Reactor Observation Glass

One glass block for walls and roofs. Adjacent panes connect. Older Roof Windows still work and return Observation Glass when broken or crafted alone.

<Recipe id="essenceindustry:reactor_glass" />


## Nuclear Reactor Controller

Set dimensions, check the structure, then control the reactor. Open the Field Guide for a starter build.

<Recipe id="essenceindustry:reactor_controller" />

## Item Port

Right-click to choose Input or Output. Use Input for reactor fuel or fuel-plant ingredients, and Output for solid spent fuel or plant products. Both modes use this same crafted block.

<Recipe id="essenceindustry:reactor_fuel_input" />

## Fluid Port

Right-click to choose Input or Output. Reactors take water in and send steam out; turbines take steam in and return water. Both modes use this same crafted block.

<Recipe id="essenceindustry:reactor_coolant_in" />

## Energy Port

Exports reactor and turbine power; supplies FE to fuel processors. Its direction follows the connected machine automatically.

<Recipe id="essenceindustry:reactor_energy_out" />

## Reactor Fuel Assembly

Fuel and control share one section. Stack a complete interior column and place one Control Actuator in the roof directly above it. The absorber moves inside the central guide between the fuel rods.

<Recipe id="essenceindustry:reactor_fuel_assembly" />

## Reactor Control Actuator

Place one above every fuel assembly column. The controller adjusts the integrated absorbers together. Fuel plants use the listed number of actuators anywhere in their roof.

<Recipe id="essenceindustry:reactor_actuator" />

## Process Conduit

Structural pipe used by the Fuel Reprocessor layout. Reactors do not require internal coolant pipes; Steam mode uses a Fluid Port set to Input for water and another set to Output for steam.
