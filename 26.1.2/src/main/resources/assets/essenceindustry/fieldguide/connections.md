# Power and transport

## Power

Supply FE, or connect to a powered ME network. The Array draws power for its shared processing engine. A disconnected or unpowered machine pauses work.

## ME connection

AE cables can connect to the controller, Input / Pattern Hatches and Output Ports. The visible connector positions matter; decorative casing details are not cable ports.

Every Input / Pattern Hatch adds **36 processing-pattern slots**. Use the arrows in Patterns to change pages.

## Ordinary item transport

A Furnace, Blast Furnace or Smoker Array can accept ordinary raw items through its input hatches, with no ME crafting job. Use hoppers or item pipes. It uses FE rather than furnace fuel.

Pull the cooked items from Output Ports. For example: **raw iron in, iron ingots out** in a Furnace Array. A Smoker accepts food; it does not smelt raw iron.

Raw item input currently covers these cooking families. Multi-ingredient processing uses encoded ME processing patterns.
