# Encode one native operation

Use an AE2 **processing pattern**, matching a real recipe for the installed machine. Encode its exact ingredients, quantities and outputs.

## Example: Circuit Slicer

Encode **1 Gold Block -> 9 Printed Logic Processors**. Install Circuit Slicers, add the pattern and request processors through ME autocrafting.

You do not need to multiply the pattern for every installed machine. Larger requests are divided into native operations within the Array's available capacity.

## Different recipes together

Different accepted patterns stay separate jobs. Their inputs are not merged into a shared crafting grid. More installed machines allow simultaneous operations; installing two machines does not multiply the result of a single recipe for free.

## Native batches

If a machine's native recipe makes four items, encode the ingredients and all four outputs. An eight-item request needs two native operations.

A displayed pattern must still match a native recipe. Merely writing a desired output into a pattern cannot create a new transformation.
